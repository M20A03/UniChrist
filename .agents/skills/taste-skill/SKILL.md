# 🎨 Taste Skill: High-Craft Aesthetic Auditor

Based on `leonxinx / Taste-Skill` and the Anti-AI Vibe-Coded checklist.

## Core Directives:
1. **Ban Generic AI Clichés:**
   - No purple/violet gradients as default backgrounds.
   - No Lucide icons randomly decorating every heading.
   - No floating sparkle (`✨`) or brain (`🧠`) emoji spam.
   - No default "Vite + React" page titles or template favicons.
2. **Typography Hierarchy:**
   - Avoid generic Inter/Geist font overload; prefer intentional pairings (e.g. Cinzel, Space Grotesk, JetBrains Mono, or clean editorial serif).
3. **Layout Discipline:**
   - Ban predictable 3-card horizontal rows and repetitive bento boxes.
   - Ensure intentional whitespace and micro-interaction responsiveness.
