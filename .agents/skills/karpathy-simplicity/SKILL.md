# 🧠 Karpathy Simplicity Principles

## Tenets:
1. **Understand Every Line:** Write code from first principles before importing massive abstractions.
2. **Minimal Abstraction:** Don't wrap a 3-line function in a 5-layer class hierarchy.
3. **Transparent State:** Keep variables explicit and verifiable; avoid magical framework side effects.
4. **Performance by Default:** Flat arrays, deterministic iteration, and vectorized operations over nested callbacks.
